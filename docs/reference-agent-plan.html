1Current Reference Agent Audit

referenceService.js · Composer.tsx
Current References Card (Reported Screenshot)
Only accepts DOIs, links, arXiv IDs, or bare paper titles. Immediately writes to .bib with no entry-type picker, no manual creation, no ISBN/book lookup, and no page/section locator options.

5 Concrete Root Causes in referenceService.js

1. No ISBN detection or book APIs: detectInput() (line 70) only checks DOI, arXiv, and URL. ISBNs and book titles fall through to Crossref, which misses most textbooks and strips edition/ISBN.

2. Formatted references fail: A single APA/IEEE/Chicago citation under 200 chars bypasses splitWithLLM() (line 130) and fails Crossref’s strict titleMatch(). Pasting raw @book{...} gets split line-by-line into junk queries!

3. Limited entry types: TYPE_MAP (line 359) only knows 7 types—no @manual, @inbook, @software, @online, or @standard, and no way to create a manual entry.

4. Zero page/section locators: insertCite() in Composer.tsx:172 only emits bare \cite{Key} with no [pp.~42--45] or [Ch.~3, §3.2] postnote.

5. Blind auto-append: resolveItems() writes straight to .bib before the user can verify/edit fields or change the Biber type.

5Matching Assistant UI Upgrade (Composer.tsx Parity)

        Composer.tsx · AgentHeader.tsx · glass.css
      


      

        

          
Why Assistant Needed Alignment

          

            The floating Composer.tsx card hosts both Assistant and
            References. Upgrading References into a Liquid Glass macOS 27 studio while leaving
            Assistant with its old Thinking: Recommended (High) dropdown, single cramped bottom row, and
            unused Image → LaTeX menu would split the card’s visual identity in half.
          

        

        

          
4 Parity Upgrades Applied to Assistant

          
1. Shared Liquid Glass Shell: Same 18px radius, blur(28px) saturate(1.8), specular rim, and top segmented header with History & New chat line icons.

          
2. Spectrum Quick-Action Bar: Polish (amber), Rewrite (blue), Restructure (green), Translate (purple) in the exact same 26px chip strip as References’ presets.

          
3. Shared 2-Row Composer & Cascading Pill: Replaces <Select className="composer-effort"> with the exact same Spectrum Model & Effort Cascading Pill used in the Agent Workspace.

          
4. Unified Proposal Card: Suggested edits render in the same .draft-card container as Reference Drafts, with one-click Apply change, Review diff, and Continue in Spectrum Agent.

FilePlanned Changes

          
            

              apps/backend/src/services/referenceService.js
              
                1. Add ISBN-10/13 detector + checksum validator, and raw BibTeX/RIS detector before splitLines().

                2. Add recordFromIsbn() & searchBooks() querying Open Library + Google Books.

                3. Remove the 200-char gate on formatted citation parsing: extract structured CSL fields from APA/IEEE/Chicago strings, verify online, and fall back to the parsed record if unindexed.

                4. Expand toBibtex() to emit full Biber/BibLaTeX fields (@manual, @inbook, @software, @online, isbn, edition, chapter, version, organization, urldate) and add a dry-run / resolve-only mode (preview: true) so nothing writes to .bib until confirmed.
              		
            

            

              apps/backend/src/routes/references.js
              Add POST /api/references/commit accepting a user-customized entry (type, key, fields) with duplicate & key-uniqueness validation.
            

            

              apps/frontend/src/editor/Composer.tsx & ReferenceDraftCard.tsx
              Replace instant-add flow with the interactive Reference Draft Card (Biber entry-type pills, dynamic field editor, + New manual entry button, and Page/Chapter/Section locator bar). Update the sibling Assistant tab in Composer.tsx to match: same Liquid Glass shell, Spectrum quick-action chip strip, unified 2-row composer footer, cascading Model & Effort pill (replacing <Select className="composer-effort">), and drop the unused Image → LaTeX menu.
            

            

              apps/frontend/src/editor/shared.tsx
              Extend citationText(api, keys, locator) to format LaTeX/BibLaTeX postnotes (\cite[pp.~42--45]{Key}, \parencite[Ch.~3]{Key}), Typst supplements (#cite(<Key>, supplement: [pp. 42–45])), and Pandoc Markdown ([@Key, pp. 42-45]).
