Section 01

Goals, Architecture Shift & Compatibility Contract

Today's Spectrum runs three layers: a thin Tauri 2 Rust shell (src-tauri/src/main.rs, 1.8k LOC), a React + CodeMirror 6 + PDF.js frontend (apps/frontend, 98.5k LOC), and a Node.js + Fastify + LangGraph backend (apps/backend, 88.2k LOC) communicating over localhost HTTP/SSE with a session cookie. The rewrite collapses all three into one native Rust binary with direct in-process calls, GPU-rendered UI via GPUI, and zero embedded browser or Node runtime.

Non-Negotiable Compatibility Contract

  • 100% v2.8.1 Feature Parity (No Features Dropped): Spectrum v2.8.1 is the binding feature baseline. Every capability in 2.8.1 must be present in 3.0.0 (LaTeX/Typst/Markdown editing & compiling, PDF preview, SyncTeX, LSP, Harper/Hunspell/LanguageTool, AI assistant & personas, local agents & MCP/ACP, References/Zotero/Research, Preflight Review, Checkpoints & GitHub sync, LaTeX ↔ Typst converter, Jyutping, Diagram Composer, Document Parsers/MinerU, Snippets, To-dos, Sticky Notes, Figure/Math preview, Typst Universe).
  • Preserved Core Sectional Layout: Keep the familiar 2.8.1 spatial structure — collapsible Left Sidebar with Files / Research / To-dos tabs at top, the Outline docked as a collapsible panel at the bottom-left (above Settings), Editor on the left/center, and PDF preview on the right (with Editor / Split / PDF view modes). Reorganising individual buttons, toolbars, and menus for cleaner native UX is encouraged.
  • Projects stay ordinary folders: Existing folders in ~/Documents/Spectrum (LaTeX, Typst, Markdown) open in place without migration.
  • Reuse bundled assets verbatim: Keep existing templates/, dictionaries/ (SCOWL / AussieDic + licences), skills/, engines.json checksums, and bundled CJK/mono fonts.
  • Engine compatibility: Reuse the exact same bundled tectonic, typst, texlab, and on-demand tinymist, biber, pandoc binaries + system TeX Live / MiKTeX detection.
  • Settings & secrets migration (2.x → 3.0.0): Read existing Spectrum 2.8.0 settings JSON gracefully on first launch (non-destructively migrating to v3.0.0 schema); store API keys and GitHub OAuth tokens in the OS keychain (macOS Keychain / Windows Credential Manager) via keyring.
  • Version 3.0.0 across all metadata: Set version = "3.0.0" in [workspace.package] and inherit via version.workspace = true in every crate, macOS Info.plist (CFBundleShortVersionString / CFBundleVersion), Windows branded setup metadata (spectrum-win-setup), and About/Update dialogs.

Flexible GPU Gutter Design & Behaviour
  • Visual craft: Crisp rounded vertical rails (e.g. 2–2.5px wide, 2–3px gap, up to 8 nesting depths) rendered directly on the GPU canvas — can use subtle top/bottom end-caps or soft glow on the active scope.

/// Active innermost scope gets full opacity (0.92); outer scopes stay subtle (0.52).
pub fn paint_scope_bars(
    window: &mut Window,
    theme: &SpectrumTheme,
    gutter_origin: Point<Pixels>,
    line_height: Pixels,
    depth: u8,
    is_active_scope_line: bool,
) {
    let bar_w = px(2.5);
    let gap = px(2.5);
    let visible = depth.min(8) as usize;
    for level in 0..visible {
        let mut color: Hsla = theme.scope_bar_color(level % 6);
        color.a = if is_active_scope_line && level + 1 == visible { 0.92 } else { 0.52 };
        let x = gutter_origin.x + px(6.0) + (bar_w + gap) * (level as f32);
        let bounds = Bounds::new(
            Point::new(x, gutter_origin.y + px(1.0)),
            Size::new(bar_w, (line_height - px(2.0)).max(px(2.0))),
        );
        window.paint_quad(fill(bounds, color).corner_radii(px(1.25)));
    }
}

use std::future::Future;
use std::sync::OnceLock;
use tokio::runtime::{Builder, Runtime};

static TOKIO_RT: OnceLock<Runtime> = OnceLock::new();

pub fn init_tokio_runtime() {
    TOKIO_RT.get_or_init(|| {
        Builder::new_multi_thread()
            .worker_threads(4)
            .thread_name("spectrum-tokio")
            .enable_all()
            .build()
            .expect("failed to initialize Spectrum Tokio runtime")
    });
}

/// Runs any Tokio future (reqwest, LSP, MCP, compile) safely from GPUI's smol executor.
/// Returns Err if the background task was cancelled or panicked (zero .unwrap()/.expect()!).
pub async fn spawn_tokio<F, T>(fut: F) -> Result<T, RuntimeError>
where
    F: Future<Output = T> + Send + 'static,
    T: Send + 'static,
{
    let rt = TOKIO_RT.get().ok_or(RuntimeError::NotInitialized)?;
    let (tx, rx) = futures_channel::oneshot::channel();
    rt.spawn(async move {
        let _ = tx.send(fut.await);
    });
    rx.await.map_err(|_| RuntimeError::TaskCancelled)
}

1. Module & Visibility Discipline
  • Use modern Rust 2018+ module layout: foo.rs + foo/bar.rs. Never create mod.rs files.

3. Mandatory GPUI Entity, Async & Focus Pattern

Every interactive view in spectrum-* must follow this exact canonical skeleton:

use gpui::{
    actions, div, prelude::*, Context, Entity, EventEmitter, FocusHandle,
    Focusable, Subscription, Window,
};
use spectrum_theme::{AreaHue, SpectrumTheme};

actions!(compile, [CompileDocument, StopCompile]);

pub enum CompilePanelEvent {
    JumpToDiagnostic { path: std::path::PathBuf, line: u32 },
}

pub struct CompilePanel {
    focus_handle: FocusHandle,
    /// ALWAYS store subscriptions so they drop cleanly with the view.
    _subscriptions: Vec<Subscription>,
    status: CompileStatus,
}

impl CompilePanel {
    pub fn new(
        project: Entity<ProjectStore>,
        window: &mut Window,
        cx: &mut Context<Self>,
    ) -> Self {
        let focus_handle = cx.focus_handle();
        let sub = cx.subscribe_in(&project, window, Self::on_project_event);
        Self {
            focus_handle,
            _subscriptions: vec![sub],
            status: CompileStatus::Idle,
        }
    }

    fn on_compile(&mut self, _: &CompileDocument, _window: &mut Window, cx: &mut Context<Self>) {
        // NEVER block the foreground thread. Spawn async work and update via WeakEntity.
        cx.spawn(async move |this, cx| {
            let result = crate::runtime::spawn_tokio(run_compile_job()).await;
            let _ = this.update(cx, |panel, cx| {
                panel.status = CompileStatus::from_result(result);
                cx.notify();
            });
        })
        .detach();
    }
}

impl EventEmitter<CompilePanelEvent> for CompilePanel {}

impl Focusable for CompilePanel {
    fn focus_handle(&self, _cx: &gpui::App) -> FocusHandle {
        self.focus_handle.clone()
    }
}

impl Render for CompilePanel {
    fn render(&mut self, _window: &mut Window, cx: &mut Context<Self>) -> impl IntoElement {
        let theme = cx.global::<SpectrumTheme>();
        let area = theme.area(AreaHue::Writing);

        div()
            .id("compile-panel")
            .track_focus(&self.focus_handle)
            .key_context("CompilePanel")
            .on_action(cx.listener(Self::on_compile))
            .bg(theme.bg_panel)
            .border_1()
            .border_color(theme.border)
            .text_color(area.text)
            .child("...")
    }
}
